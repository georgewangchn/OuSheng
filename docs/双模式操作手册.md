# 双模式操作手册（最简步骤）

> 白天有人 → 你指挥；晚上无人 → cruise-loop 自动值守。

---

## 白天（有人模式）

**1. 发任务**

web 驾驶舱（:18000/cruise）→「快速发单」→ 选系统 + 标题 → 建单。

**2. 让 agent 开工**

在 web 里打开对应域的 opencode session，发一句：

> 看看你的 pending work，领活开工。

完事。交互、纠偏、答疑都在这个 session 里直接聊。

---

## 晚上（无人模式）

**1. 发今晚要做的单**（同白天：web 驾驶舱建单）

**2. 每个座位启动 runner**（a 机 shell 执行，不进 opencode）：

```bash
/data/tide/data/scripts/cruise-loop.sh  /data/tide/kanban data  /data/tide/data  20 600 22:00-07:00
/data/tide/mlake/scripts/cruise-loop.sh /data/tide/kanban mlake /data/tide/mlake 20 600 22:00-07:00
/data/tide/ui/scripts/cruise-loop.sh    /data/tide/kanban ui    /data/tide/ui    20 600 22:00-07:00
/data/tide/lhcp/scripts/cruise-loop.sh  /data/tide/kanban lhcp  /data/tide/lhcp  20 600 22:00-07:00
```

runner 自动领活、执行、交付、收尾——你不用管。

**3. 挂 cron（永久值守，只需设一次）**：

```bash
crontab -e
# 加一行（22:00 自动启动，07:00 时窗外自动停）：
0 22 * * * /data/tide/data/scripts/cruise-loop.sh  /data/tide/kanban data  /data/tide/data  20 600 22:00-07:00 >> /var/log/cruise-data.log 2>&1
```

---

## 明早看结果

```bash
ousheng cruise status --hours 12
```

一屏看到：交付了多少、空转了谁、挂起等你的有哪些。打开 web /cruise 看详情。

---

## 要点

| 场景 | 怎么做 | 不需要 |
|---|---|---|
| 白天有人 | web 发单 + 开 session 一句"开工" | cruise-loop.sh |
| 晚上无人 | 每座位启动 cruise-loop.sh（或 cron） | 开 opencode 窗口 |
| 看结果 | `cruise status` 或 web /cruise | 逐个窗口查 |
| 遇到门（拍板/ack） | 自动挂起，晨间简报列出 | 夜间处理 |
