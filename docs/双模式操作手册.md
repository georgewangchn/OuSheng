# 双模式操作手册（最简步骤）

> 白天有人 → 你指挥；晚上无人 → 巡航驱动值守。**PM 唯一操作面 = web 驾驶舱**
> （§50-A，2026-11-16 拍板）；opencode 会话 = 对话例外通道（不写板不拍板）；
> 个人机 CLI = 只读观测（写板必经驾驶舱所在机——单写源永不分叉，§48）。

---

## 一次性部署（每座位一次）

```bash
# 座位仓（如 A 机 /data/tide/data）：
ousheng adapter install --cruise --workspace <板仓> --actor <座位>
# systemd 面（点火载体）：
cp scripts/ousheng-cruise@.service /etc/systemd/system/ && systemctl daemon-reload
# 参数文件 /etc/default/ousheng-cruise-<座位>：
#   CRUISE_REPO=<座位仓>
#   OUSHENG_CRUISE_ARGS="<板仓> <座位> <系统> <座位仓> 20 600 22:00-07:00"
#   OC_MODEL_WAIT=deepseek/deepseek-flash   # 值守轻活=弱模型
#   OC_MODEL_CODE=<强模型>                  # 编码活=强模型（配额恢复即回切，
#                                           #  勿因应急填 flash 后忘改——11-15 实锤）
```

驾驶舱启动（PM 机/板仓机）：`ousheng web --addr 0.0.0.0:7878 --token <自设令牌>`
（回环绑定免 token；非回环必 token——§50-E。手机浏览器开 `/login` 输令牌进舱。）

---

## 白天（有人模式）

1. **发任务**：驾驶舱「快速发单」（task/bug；feature/requirement 先起 design）。
2. **让 agent 开工**：驾驶舱「点火」按钮（或该座位 opencode 会话说一句「领活开工」）。
3. **拍板/答疑**：驾驶舱「挂起待你处理」批量 decide/ack；座位提问攒在单内 `Q:` 条目。

## 晚上（无人模式）

1. **离场三步**：`ousheng pm away`（present 挂夜 = 全队空等烧 token，11-13→16 实锤）
   → 驾驶舱发当晚要做的单 → 每座位点「点火」。
2. 驱动器每轮给**一句话方向**（sync 并推进，直至完成/挂起——§51 绳牛裁决：不替模型排活），
   模型自己拉板、定序、连做；三闸/水位/预算是治理闸兜底。
3. **禁**：pm 会话手动巡航（PM 是方向盘不是轮子，§50-A 死法）、手搓/手改驱动脚本
   （驱动器=协议资产，升级=重跑 `adapter install --cruise`，§37）。

## 晨检仪式（每天第一件事，5 分钟）

1. `ousheng cruise status --hours 12` / 驾驶舱整体状态：交付/新增/空转/挂起一屏。
2. **清挂起**：驾驶舱批量 decide/ack/回 `Q:`——不清 = 白天 agent 领新活再挂，滚雪球。
3. **presence 复声明**：在场 = present；过夜忘切 = 点火输出会提醒。
4. `ousheng cruise report --hours 12`：看**纯记账轮占比**（>50% = 空转信号）与
   **板面交付 × 代码仓提交**对照（板交 32 单/代码 0 提交 = 记账通胀，抽 3 单验证据）。
5. 需要 continuation 就再点火；`--stop` 停火。

## 要点速查

| 场景 | 怎么做 | 禁止 |
|---|---|---|
| PM 写板 | 驾驶舱（唯一写面） | 个人机 clone 写板（双写源=分叉=停摆，§48） |
| PM 拍板 | 驾驶舱 decide/ack | 在 opencode 会话里指挥 agent 拍板（身份≠pm，必被拒） |
| 启动巡航 | `cruise ignite --seat X` 或驾驶舱点火（唯一入口） | cron 定时自启（§45 已废）/ pm 手动巡航 / 手搓脚本 |
| 停巡航 | `cruise ignite --seat X --stop` / 驾驶舱停火 | — |
| 驱动器升级 | 二进制替换（原子 `mv`）→ `adapter install --cruise` 重跑 → `doctor` | 手改 scripts/cruise-loop.sh（doctor 会 FAIL） |
| 遇门（拍板/ack） | 挂起进晨报，晨间清 | 夜间绕门 |
| token 预算 | 可选 `OUSHENG_TOKEN_BUDGET`（默认关；晨报看累计） | 裸奔不设预算不看晨报 |
