# 通宵之后，AI 的活还在，token还便宜

### 一个 git 仓 + 一个循环 + 四行命令

> 下班前跑四行命令，AI 通宵自主开发。板派活、AI 干活、三道门保安全，早上一条命令看全局。晚间 token 便宜，无人值守，错峰开发。

---

## 问题是：你下班了，AI 停了

给 AI 窗口留一句"修这个 bug"——AI 干半小时，修完了，停了。

下一个任务还在板上。你翻出五个窗口挨个发指令。AI 又干半小时又停。再来。

问题不在 AI 不干活。在你走了之后，没人替你发指令。

---

## 解法

OuSheng 把任务、状态、证据、共识装进一个 git 仓。AI 从仓里领活干活。

巡航模式加一个东西：**一个 shell 循环替你发指令**。

```bash
# 下班前跑四行（每系统一行）
./scripts/cruise-loop.sh /data/xyz/kanban alpha /data/xyz/alpha 20 600 22:00-07:00
./scripts/cruise-loop.sh /data/xyz/kanban bravo /data/xyz/bravo 20 600 22:00-07:00
./scripts/cruise-loop.sh /data/xyz/kanban charlie /data/xyz/charlie 20 600 22:00-07:00
./scripts/cruise-loop.sh /data/xyz/kanban delta /data/xyz/delta 20 600 22:00-07:00
```

AI 领活干活，交证据，推送，领下一个。你走人。

---

## 早上一条命令

```
ousheng cruise status --hours 12
```

```
== 巡航摘要（近 12h）== 宪章：已立
  alpha 仓夜间提交 14
交付 6 单｜新增 2 单
空转嫌疑 0 项
挂起等 human 2 项：
  [拍板] cache-strategy
  [C2]   T-089
```

干了多少、空转没有、哪些等你拍板。一屏。

---

## 巡航模式的三个优势

- **错峰开发**：晚间/节假日 LLM token 价格低谷，同样预算干更多活
- **无人值守**：AI 自主领活、执行、交付、收尾，不需要你开窗口发指令
- **自主优化**：AI 按板上优先序自主推进，多系统并行不串线

---

## 为什么 AI 不会搞出破坏

三道门在代码里，不在对话里：

- 契约改了必须有 commit 证据——"做完了"变成可验证的事实
- 破坏性接口变更必须有人确认——夜里没人确认就挂起，不绕过
- 方案必须 human decide——agent 不能自拍共识
