# OuSheng — 㸸绳

> "㸸"（òu）是河南方言里"㸸"的叫法，"绳"是牵引绳。OuSheng = 㸸绳 = 㸸绳。

多人 AI Coding 协作工具。

定位：套在 AI Coding 这头㸸鼻子上的**牵引绳** —— 最小接触点，只给方向，绝不替㸸使劲。机制与具体 AI Coding 工具（Claude Code / opencode / Codex / Pi / 人）解耦。

核心：一块小看板（reference）+ 一套接口标准（量纲），协调多个"人 + AI"协作，无需共享 Memory、无需中心验证、无需 Ontology。

## 名字来历

"OuSheng" 来自河南方言。河南（尤其南阳一带）把"㸸"读作 òu，对应的字是"㸸"。农村说"放㸸"就是放㸸，"牤㸸"是公㸸，"㸸娃儿"是㸸犊。

OuSheng = 㸸（㸸）+ 绳（牵引绳）= 套在㸸鼻子上的那根绳。

AI Coding 是一头力气巨大的㸸，这个工具就是那根绳。绳越简单、越轻、越不抢㸸的活，系统越成功。
